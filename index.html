Global Vertiport Data Exchange Standard for AAM

Harmonizing Vertiport Data for the Advanced Air Mobility Era

VIXM (Vertiport Information Exchange Model) is an internationally aligned data specification designed to seamlessly exchange static infrastructure, dynamic operational status, and capacity constraints across the UAM ecosystem.

View Payloads GitHub Repository

Core Scope of VIXM

Capturing end-to-end ground & approach dimensions for vertiports

Static Infrastructure

TLOF/FATO geometry, obstacle clearance surfaces (OIS), passenger boarding gates, vertiport identification, and hazardous area constraints.

Dynamic Operations

Real-time pad availability, charging/MRO station status, slot reservations, turnaround times, and temporary operating restrictions.

SWIM Integration

Full semantic interoperability with Air Traffic Management (ATM) & UTM systems via standardized XML (GML) and JSON payloads.

Aeronautical Information Landscape

Position of VIXM alongside established global exchange standards

Standard Primary Domain Focus Area Key Exchange Target
AIXM Aeronautical Information Airspace, Routes, Traditional Aerodromes AIS / NOTAM Providers
FIXM Flight & Flow Information Flight Plans, Trajectory, 4D Profile ATM / Airline Operations (AOC)
IWXXM Weather Information Meteorological forecasts, Observations MET Services
VIXM Vertiport Information Vertiport Physical & Tactical Resource State Vertiport Operators (VPO), PSU, Fleet Operators
